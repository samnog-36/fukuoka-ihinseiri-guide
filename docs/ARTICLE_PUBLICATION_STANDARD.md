# 記事公開・更新基準

福岡遺品整理ガイドでは、記事の品質・表示形式・信頼性を維持するため、公開または大幅更新のたびに本基準を確認します。架空の運営者、資格、利用者の声、実績は掲載しません。

## 記事本文の必須要素

| 項目 | 基準 |
|---|---|
| 本文 | 文字数を目的にせず、検索者の疑問に具体的に答え、同一テーマの記事との重複を避ける |
| 独自性 | 福岡県・対象自治体の制度、具体的な判断基準、比較表、確認手順など、そのページを読む理由が明確にあること |
| 根拠 | 制度・法律・税・自治体ルール・統計・料金等の事実は、一次情報または確認可能な出典を優先する |
| 断定表現 | 出典から確認できない数値・割合・「必ず」「正確」「専門家監修」等の表現を使用しない |
| 目次 | 長文記事では本文前に設置し、各見出しへ移動できる状態にする |
| 見出し | H1はページに1つ。H2・H3は内容の階層に沿って使う |
| 画像 | 実際に表示される画像を使用し、内容が分かるalt属性、width・heightを設定する。装飾だけの大量画像は避ける |
| 編集情報 | 記事末尾に「福岡遺品整理ガイド編集部」の編集情報を表示する |
| 公式確認先 | 記事のジャンルに合う公的機関・自治体・公式団体への確認先を表示する |
| 問い合わせ | 内容の訂正依頼・お問い合わせとして既存フォーム（`/contact/`）へ案内する |

## 公開前の品質判定

次のいずれかに当てはまる記事は、新規公開せず、既存記事への統合または大幅な再編集を優先します。

- タイトル中の地名だけを差し替えれば成立する地域量産ページ
- 他の記事と結論・構成・説明の大半が同じ記事
- 検索キーワードを満たすためだけに作成した記事
- 一次情報を要約しただけで、読者の判断に役立つ整理・比較・具体例がない記事
- 根拠を確認できない費用、割合、期間、ランキング等を含む記事
- 実在しない専門家、監修、体験談、口コミ、利用実績を示唆する記事

## SEO・技術設定の必須要素

| 項目 | 基準 |
|---|---|
| title・description | 記事固有の内容を簡潔に説明し、他記事と重複させない |
| canonical | 正式URLを指定する |
| OGP | title・description・image・URLを設定する |
| 構造化データ | Article・BreadcrumbListを設定し、実態に合わないOrganization/ProfessionalService等を付与しない |
| 更新日 | 内容を実際に確認・更新した日だけを表示し、`dateModified`・sitemapの`lastmod`と整合させる |
| AdSense | 広告を表示する本文ページのみで読み込み、プライバシーポリシー等の情報ページでは不要な広告読み込みを避ける |
| サイトマップ | インデックスさせる価値がある正規URLだけを掲載する |

## 公開前の確認手順

1. 対象記事の検索意図と既存記事の重複を確認します。
2. 法律・制度・自治体ルール・統計・料金の根拠を一次情報で確認します。
3. 根拠不明の数値、過度な断定、誤解を招く専門家表現を削除します。
4. title、description、canonical、OGP、構造化データを確認します。
5. 記事内リンク・公式外部リンク・画像・モバイル表示を確認します。
6. `python3 scripts/verify_adsense_trust_updates.py` と `git diff --check` を実行します。
7. 公開後、Search Consoleでインデックス状況・検索流入を確認し、価値の低いページは統合・noindex・削除を検討します。

## 情報源の考え方

制度・手続き・処分方法・税・相続・自治体サービスの記述では、国・自治体・裁判所・公式団体の一次情報を優先します。地域固有の内容は、対象の市区町村の公式案内を確認します。制度改正や自治体運用の変更があり得るため、実行前の公式確認を促す表記を残します。

## AdSense再審査時の考え方

AdSenseの審査対策を目的に記事数を増やしません。再審査前は、サイト全体を見て「読者にとって独自の価値が弱いページ」を減らすことを優先します。広告のためだけに存在するページを作らず、本文・運営情報・プライバシー情報・お問い合わせ導線が明確な状態にします。
