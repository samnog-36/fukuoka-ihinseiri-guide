# 記事公開・更新基準

福岡遺品整理ガイドでは、記事の品質・表示形式・信頼性を維持するため、公開または大幅更新のたびに本基準を確認します。架空の運営者、資格、利用者の声、実績は掲載しません。

## 記事本文の必須要素

| 項目 | 基準 |
|---|---|
| 本文 | 日本語で3,000字以上を目安に、検索語だけを目的としない具体的で役立つ説明にする |
| 目次 | 本文前に設置し、各見出しへアンカーで移動できる状態にする |
| 見出し | H1はページに1つ。H2・H3は内容の階層に沿って使う |
| 画像 | 実際に表示されるWebP画像を使用し、内容が分かる日本語のalt属性、width・heightを設定する |
| 編集情報 | 記事末尾に「福岡遺品整理ガイド編集部」の編集情報を表示する |
| 公式確認先 | 記事のジャンルに合う公的機関・自治体・公式団体への確認先を表示する |
| 問い合わせ | 内容の訂正依頼・お問い合わせとして既存フォーム（`/contact/`）へ案内する |

## SEO・技術設定の必須要素

| 項目 | 基準 |
|---|---|
| title・description | 記事固有の内容を簡潔に説明し、他記事と重複させない |
| canonical | 正式URLを指定する |
| OGP | title・description・image・URLを設定する |
| 構造化データ | Article・BreadcrumbListを設定し、authorは「福岡遺品整理ガイド編集部」とする |
| 更新日 | 表示日・`dateModified`・sitemapの`lastmod`を同じ日付にそろえる |
| AdSense | `<head>`に既存の `ca-pub-4944616437202027` のスクリプトを含める |
| サイトマップ | 新規記事URLを `sitemap.xml` に追加する |

## 公開前の確認手順

1. 画像をWebPへ変換し、実ファイル・HTMLのパス・公開後のHTTPステータスを確認します。
2. カテゴリ一覧、ブログ一覧、トップページ、該当ガイドページのカードを既存のカード構造で更新します。
3. `python3 scripts/apply_adsense_trust_updates.py` を実行し、編集情報・公式確認先・フッター導線・CSSバージョンを統一します。
4. `python3 scripts/verify_adsense_trust_updates.py` と `git diff --check` を実行します。
5. GitHubへpush後、Cloudflare Pagesで記事URL・画像・トップページ・モバイル表示を確認します。

## 情報源の考え方

制度・手続き・処分方法・税・相続・自治体サービスの記述では、国・自治体・公式団体の一次情報を優先します。地域固有の内容は、必ず対象の市区町村の公式案内を確認します。制度改正や自治体運用の変更があり得るため、実行前の公式確認を促す表記を残します。
